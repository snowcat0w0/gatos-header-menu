# Gato's Header Menu (gatos-header-menu)

이 모듈은 AI를 써서 만들었어요.

## 이게 뭐예요?

Foundry VTT에서 캐릭터 시트 창을 열면, 창 맨 위 제목 줄에 버튼이 줄줄이 생길 때가 있어요. 모듈을 많이 깔수록 더 많아져요. 이 모듈은 그 버튼들을 **⋮ 메뉴 하나**에 모아 숨겨 줘요.

```
전: 제목 · PopOut! · Sheet · HUD Overlay URL · Configure · Wallet · Theatre · Add to Stage · Craft · Cinematic FX · Prototype Token · 태그 · Close
후: 제목 · PopOut! · Prototype Token · ⋮ · 태그 · Close
```

어떤 게임 시스템에서도 써요. PF1 시트처럼 버튼이 많은 옛 모양 창을 위해 만들었어요.

이 폴더의 모듈은 Foundry VTT 14 버전용이에요(`foundry-v14` 브랜치). 13 버전을 쓰면 `master` 브랜치를 받아요.

## 먼저 준비할 것

이 모듈은 **gatos-lib** 모듈이 있어야 돌아가요. 둘 다 설치하고 둘 다 켜 주세요. gatos-lib가 꺼져 있으면 월드에 들어갈 때 경고가 떠요.

**lib-wrapper** 모듈이 있으면 다른 모듈과 더 잘 어울려요. 없어도 돌아가요.

## 설치하는 법

1. Foundry 첫 화면(설정 화면)에서 **애드온 모듈** 탭을 열고 **모듈 설치**를 눌러요.
2. 창 맨 아래 **매니페스트 URL** 칸에 아래 주소를 붙여 넣고 **설치**를 눌러요.

   ```
   https://raw.githubusercontent.com/snowcat0w0/gatos-header-menu/foundry-v14/module.json
   ```

3. "gatos-lib도 함께 설치할까요?" 하고 물어보면 **예**를 눌러요. 이미 있으면 안 물어봐요.
4. 월드에 들어가서 **게임 설정 → 모듈 관리**에서 **Gato's Library**와 **Gato's Header Menu**를 둘 다 체크하고 저장해요.

주소로 설치가 안 되면 [Releases](https://github.com/snowcat0w0/gatos-header-menu/releases) 페이지에서 `gatos-header-menu.zip`을 받아 풀고, 그 폴더를 `Data/modules/gatos-header-menu`에 넣어도 돼요.

## 어떻게 써요?

켜 두면 바로 돼요. 시트를 열면 버튼들이 ⋮ 메뉴 안에 들어가 있어요.

- **⋮**를 누르면 숨겨진 버튼들이 나와요. 누르면 원래 버튼과 똑같이 동작해요.
- **닫기(X)** 와 **프로토타입 토큰** 버튼은 처음부터 밖에 남아 있어요.
- 밖에 남길 버튼을 바꾸고 싶으면(GM만), ⋮ 메뉴 맨 아래 **"표시할 버튼 고르기…"** 를 눌러요. 체크한 버튼은 밖에 남고 나머지는 메뉴로 들어가요. 저장하면 열려 있는 창에도 바로 적용돼요.
- 목록에는 한 번이라도 열어 본 시트의 버튼만 나와요. 안 보이는 버튼이 있으면 그 버튼이 있는 시트를 한 번 열어 보세요.
- **PopOut!** 이나 작업표시줄의 **태그** 버튼처럼 어떤 모듈이 직접 끼워 넣는 버튼은 옮길 수 없어서 그대로 있어요.

## 설정

**게임 설정 → 모듈 설정 → Gato's Header Menu**에서 바꿔요. "나만"은 내 화면에만 적용되고 "월드"는 GM이 바꾸면 모두에게 적용돼요.

| 설정 | 누구 | 뜻 |
|---|---|---|
| 헤더 버튼 접기 | 나만 | 끄면 원래대로 돌아가요. |
| 적용할 창 | 월드 | 액터 시트만 / 액터와 아이템 시트(기본) / 모든 문서 시트 / 모든 옛 모양 창 |
| 제목 표시줄에 남길 버튼 | 월드 | "표시할 버튼 고르기…"와 같은 값이에요. 보통 그 메뉴로 바꾸면 돼요. |
| 남긴 버튼은 아이콘만 | 나만 | 남긴 버튼의 글자를 빼고 그림만 보여요. |
| ⋮ 버튼에 글자 표시 | 나만 | ⋮ 옆에 "더보기"라고 써 줘요. |
| 이 개수부터 접기 | 월드 | 숨길 버튼이 이 수보다 적으면 그냥 둬요. |

## 알아두기

- 새 모양 창(Application V2)은 Foundry가 이미 ⋮ 메뉴를 넣어 줘서 이 모듈이 건드리지 않아요.
- 13 버전은 Foundry 13.351과 PF1 11.11에서 popout, lichsoma-taskbar, item-piles, theatre 같은 모듈들과 같이 켜고 확인했어요. 14 버전은 아직 실제 월드에서 테스트하지 않았어요.
